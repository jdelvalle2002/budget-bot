# Budget Bot

A personal finance manager to track expenses, automating Google Drive/Sheets integration and interacting via WhatsApp/Telegram.

## Features (Planned)
- Expense tracking via natural text (e.g., "15000 uber").
- Centralized data storage in Google Sheets / Drive.
- Telegram or WhatsApp bot integration.
- Analytical capabilities and reporting.

## Setup
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in your credentials.
4. Run the backend/bot.
